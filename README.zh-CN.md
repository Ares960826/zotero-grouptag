# Zotero GroupTag

[English](README.md) | 简体中文

为 Zotero 内置 PDF 阅读器提供类似 Chrome 的可视化标签页分组功能。

它会在 Zotero 标签栏中显示带颜色的分组标题和标签下划线。你可以创建
命名分组、折叠而不关闭 PDF，并通过右键菜单管理标签页归属。

![Zotero 标签栏中的 GroupTag 分组标题](docs/screenshot.png)

## 功能

- **彩色分组标题**：以类似 Chrome 标签页组的方式显示分组。
- **自动分配初始颜色**：新建分组会优先选用未使用的颜色；之后仍可从 33
  种颜色中手动更改。
- **标签页颜色提示**：同一组中的 PDF 标签页会显示相同颜色的下划线。
- **折叠与展开**：折叠分组只隐藏标签页按钮，不会关闭对应 PDF。
- **稳定地移动分组**：拖动折叠后的分组时会显示落点标记，周围标签页在
  松开鼠标前保持不动。
- **保持分组连续**：同一分组的标签页会保持相邻，组内仍可手动调整顺序。
- **右键菜单管理**：可新建分组、分配或移出标签页、重命名、改色、折叠、
  展开和删除分组。
- **跨会话保存**：分组与标签页归属保存在 Zotero 偏好设置中。

## 安装

1. 打开 [最新发布版本](https://github.com/Ares960826/zotero-grouptag/releases/latest)。
2. 下载 `zotero-grouptag.xpi`。
3. 在 Zotero 中依次选择 **工具 → 插件**，点击右上角齿轮图标，再选择
   **从文件安装插件…**。
4. 选择下载的 `.xpi` 文件。
5. 按 Zotero 提示重启。

## 使用方法

### 新建分组

1. 在 Zotero 中打开至少两篇 PDF。
2. 右键点击任意 PDF 标签页。
3. 选择 **Assign to New Group**（分配到新分组）。
4. 输入分组名称并确认。

第一个新分组默认使用蓝色；后续分组会尽量自动使用不同颜色。分组标签页会
自动保持连续，你也可以在组内拖动标签页调整顺序。

### 折叠或展开分组

点击彩色分组标题，或右键点击标题后选择 **Collapse Group**（折叠分组）或
**Expand Group**（展开分组）。折叠只隐藏标签页按钮，PDF 仍保持打开状态。

### 移动整个分组

展开的分组不能作为一个整体拖动，以免干扰 Zotero 原生的单标签页拖动。

如需移动整个分组，请先折叠它，然后拖动折叠后的彩色分组标题。松开鼠标前
会显示落点标记；松开后，分组会整体移动到该位置。之后可再次展开。

### 将更多标签页分配到现有分组

右键点击任意 PDF 标签页，选择 **Assign to: [分组名称]**。

### 将标签页移出分组

右键点击该标签页，选择 **Remove from Group**（移出分组）。如果这是分组中
最后一个标签页，插件会询问你是删除空分组，还是保留它供后续使用。

### 重命名、改色、折叠或删除分组

右键点击彩色分组标题，选择需要的操作。选择 **Change Color**（更改颜色）
即可从 33 种颜色的调色板中手动选择颜色。
